# SentisRender

Плагин Torch для Space Engineers: рисует на экранах игроков то, что попросят другие плагины. Сферы, кубы, цилиндры,
капсулы, лучи и лазеры, светящиеся точки, метки на HUD, строки уведомлений внизу экрана.

Сервер остаётся ванильным: рисует маленький клиентский мод, который Torch отдаёт только клиентам. Сервер этот мод не
загружает, в списке модов сервера его нет.

## Как это устроено

- **Плагин** держит список фигур и знает, кому какую показывать: всем, игроку, фракции или тем, кто ближе N метров.
  Что изменилось, он отправляет в следующем кадре. Раз в секунду заново решает, кому что видно: игроки двигаются и
  меняют фракции.
- **Клиентский мод** (`ClientMod/`) после загрузки шлёт серверу «я загрузился». В ответ получает всё, что ему сейчас
  положено видеть, а затем только изменения. Рисует каждый кадр.
- **Сообщения.** Мод и плагин обмениваются сообщениями модов игры (`SendMessageTo`, канал 47110). Формат — один общий
  файл [`Protocol.cs`](ClientMod/Data/Scripts/SentisRender/Protocol.cs), protobuf; его компилируют и мод, и плагин.
  Мод принимает сообщения только от сервера.
- **Защита от подделки.** Признака «от сервера» мало: сообщение, которое клиент разослал всем
  (`SendMessageToOthers`), сервер сам пересылает остальным клиентам, и у них отправителем значится сервер. Поэтому мод
  при загрузке придумывает случайный номер сессии и сообщает его только серверу. Сервер вкладывает номер в каждый
  пакет этому клиенту, и мод выполняет только пакеты со своим номером. Чужих номеров клиент не видит: они не проходят
  ни через рассылку, ни через других клиентов.
- **Игрок без мода** (мод не скачался или не подключён) фигур не видит. Уведомления он получает обычными
  уведомлениями игры; это можно выключить в настройках.

## Установка

1. **Плагин.** Архив со страницы Releases положить в папку `Plugins` как есть (или распаковать в
   `Plugins\SentisRender`: нужны `SentisRender.dll` и `manifest.xml`). Перезапустить Torch.
2. **Мод в мастерскую Steam.** Нужно один раз, с аккаунта Steam, у которого есть Space Engineers:
   1. `powershell -ExecutionPolicy Bypass -File tools\install-mod.ps1` кладёт мод в
      `%APPDATA%\SpaceEngineers\Mods\SentisRender`;
   2. в игре: «Моды» → `SentisRender` → «Опубликовать»;
   3. в мастерской поставить видимость **«Не в списке»** (Unlisted) или «Публичный». С видимостью «Скрытый» или
      «Только для друзей» клиенты мод не скачают.
3. **Отдать мод клиентам.** Номер мода из мастерской вписать в «Client Only Mods» плагина SentisGameplayImprovements
   (`OverrideModIds`, номера через запятую). Torch дописывает такие моды в мир только для клиентов. Перезапустить сервер.
4. **Проверка.** Зайти на сервер и набрать `!render sphere 50`. Вокруг должна появиться зелёная сфера, а
   `!render status` должен показать одного клиента с модом.

После изменения мода повторить шаги 2.1–2.2 («Обновить» вместо «Опубликовать»). Номер в мастерской не меняется.

## Команды

Для админа, в чате игры. Тестовые фигуры рисуются вокруг того, кто набрал команду. Каждая команда рисует новую фигуру
(`test:sphere:1`, `test:box:2`, ...), id она пишет в ответе.

| Команда | Что делает |
|---|---|
| `!render status` | сколько фигур, сколько клиентов с модом, сколько отправлено; список ids |
| `!render sphere [радиус=50] [цвет=green] [solid\|wire\|both] [прозрачность=80] [деления=0] [толщина=0]` | сфера вокруг вас; деления 4..90, 0 — 20; толщина рёбер каркаса в метрах, 0 — радиус / 500 (не меньше 5 см) |
| `!render box [полуразмер=10] [цвет=cyan] [solid\|wire\|both] [прозрачность=80]` | куб вокруг вас, повёрнут как вы |
| `!render cylinder [длина=50] [радиус=5] [цвет=yellow]` | цилиндр из линий вверх от вас |
| `!render capsule [длина=20] [радиус=3] [цвет=purple] [прозрачность=100]` | капсула вверх от вас |
| `!render beam [длина=200] [цвет=red] [толщина=0.3] [секунд=0]` | лазер туда, куда вы смотрите; «секунд» — время жизни, 0 — без конца |
| `!render point [радиус=2] [цвет=white] [расстояние=20]` | светящаяся точка перед вами |
| `!render marker [текст=Marker] [цвет=orange]` | метка на HUD там, где вы стоите |
| `!render color <id или вид> <цвет> [прозрачность=80]` | перекрасить фигуру; вид (`sphere`, `box`, ...) — последняя нарисованная такая |
| `!render notify <текст> [мс=3000] [шрифт=White] [all]` | строка внизу экрана: вам или всем (`all`) |
| `!render clear [префикс=test:]` | убрать фигуры, чьи ids начинаются с префикса; `*` — все |

Цвета: `green`, `red`, `gray`, `white`, `blue`, `yellow`, `cyan`, `orange`, `purple` или `#RRGGBB` / `#RRGGBBAA`.
Прозрачность от 0 (не видно) до 255 (непрозрачно). Мод умножает цвет на неё перед рисованием: так прозрачные
полигоны смешивает движок игры.

## API для плагинов

Плагин ссылается на `SentisRender.dll` (`<Private>False</Private>`, Torch загрузит её сам) и вызывает статический
класс `SentisRender.Render`. Вызывать можно из любого потока: изменения уходят клиентам в следующем кадре.

```csharp
using SentisRender;
using SentisRender.Net;

// сфера зоны: видна тем, кто ближе 10 км
Render.Sphere("zone:1", center, 3000, new Color(40, 220, 60, 60))
      .ShowTo(Audience.Near(center, 10000))
      .DrawDistance(20000);

// поменять цвет: уйдёт только эта фигура
Render.Shape("zone:1").Color(new Color(255, 40, 40, 60));

// лазер на полсекунды
Render.Line("turret:42", from, to, Color.Cyan, 0.2f).Additive().Lifetime(TimeSpan.FromMilliseconds(500));

// метка на HUD и строка внизу экрана (с id одна и та же строка обновляется, а не множится)
Render.Marker("zone:1:center", center, "АНОМАЛИЯ 45%", Color.Orange);
Render.Notify(Audience.Near(center, 3000), "ЗАХВАТ 45%", 1000, "Green", id: "zone:1:progress");

// убрать свои фигуры
Render.Clear("zone:");
```

- **Фигуры:** `Sphere`, `Box`, `Cylinder`, `Capsule`, `Line`, `Point`, `Marker`.
- **Свойства:** `Color`, `Position`, `To`, `Radius`, `HalfSize`, `Orientation`, `Text`, `Style` (`Solid`, `Wire`,
  `SolidAndWire`), `Thickness` (толщина линии или рёбер каркаса в метрах; 0 — у сферы радиус / 500, не меньше 5 см), `Material` (прозрачный материал игры: `Square`, `WeaponLaser`,
  `SafeZoneShield_Material`, `GizmoDrawLine`…), `DrawDistance`, `Detail` (деления сферы, капсулы, цилиндра: 4..90;
  сфера из n делений — около n²/2 полигонов за кадр, ровно выходят делители 360),  `Intensity`, `Additive`, `Lifetime`,
  `ShowTo`, `Remove`.
- **Кому видно:** `Audience.All` (по умолчанию), `Player(steamId)`, `Players(...)`, `Faction(factionId)`,
  `Near(center, range)` и `.Within(center, range)` к любому из них.
- **Фигура, созданная заново с тем же id,** заменяет данные прежней, а её аудиторию и время жизни сохраняет. Если
  данные не изменились, ничего не отправляется: фигуру можно строить заново хоть каждую секунду.
- **Ids — свои у каждого плагина.** Начинайте их с префикса плагина (`zone:`), чтобы `Render.Clear("zone:")` убирал
  только своё.
- **При выгрузке мира** список фигур очищается: после загрузки плагин создаёт их заново.

## Настройки

Страница плагина в Torch или `Instance\SentisRender.cfg`; все параметры с описанием — в
[`SentisRender.cfg.example`](SentisRender.cfg.example).

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `Enabled` | `true` | отправлять фигуры и уведомления |
| `ReconcileMs` | `1000` | как часто заново решать, кому что видно, когда ничего не менялось |
| `FallbackNotifications` | `true` | игроку без мода — уведомления игры |
| `DiagnosticLogs` | `false` | писать в лог каждый клиентский мод, приславший «я загрузился» |

## Сборка

Проекты SDK-формата, `net48`. Ссылки ведут на Torch и Dedicated Server в `C:\SE` (свойство `SeRoot`).

```
dotnet build SentisRender.sln -c Debug
dotnet test SentisRender.Tests
```

- **`ClientMod.Check`** компилирует скрипты мода под C# 6, как это делает компилятор скриптов игры. Белый список API
  модов он не проверяет: что мод использует, видно при его загрузке на клиенте (лог клиента,
  `%APPDATA%\SpaceEngineers\SpaceEngineers_*.log`).
- **Релиз:** тег `v1.2.3` собирает плагин и выкладывает архив в Releases (`.github/workflows/release.yml`,
  `tools/release.ps1`).
